# Asset and Content Provenance Register

The Apache-2.0 license covers copyrightable code and documentation contributed under
its terms. It does **not** establish ownership or permission for every pre-existing
devotional text, photograph, logo, trademark, or media file. Each contributor remains
responsible for supplying material they are authorized to contribute.

Before adding or replacing content/media, add one row. Use `unknown — do not publish`
when rights have not been established; such assets must not be included in a release.

| Path | Work/source | Creator or rights holder | Source URL/archive reference | License or permission evidence | Modifications | Added/reviewed by and date |
|---|---|---|---|---|---|---|
| `public/` existing assets | Pre-existing repository media | Unknown/not yet audited | Existing history | Unknown — audit before production publication | Unknown | Pending maintainer review |
| `content/` existing text | Pre-existing repository content | Mixed/unknown | Existing history | Unknown — audit before production publication | Formatting and translation may apply | Pending maintainer review |

For a new row, identify the exact file, original creator, where it came from, the full
license identifier or written permission location, edits/crops/translations, and the
reviewer/date. Preserve attribution files required by the source license. Do not assume
that public availability, religious subject matter, or AI generation grants reuse rights.
