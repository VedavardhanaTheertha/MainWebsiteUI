# Security Policy

## Supported versions

Security fixes are applied to the latest revision of the `main` branch. This static
site has no supported release branches yet.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's **Report a
vulnerability** private reporting form in the repository Security tab. Include the
affected path, impact, reproduction steps, and any suggested mitigation.

Maintainers aim to acknowledge a report within seven days, provide a status update
within fourteen days, and coordinate disclosure after a fix is available. These are
targets, not a service-level agreement. If private vulnerability reporting is not
enabled, contact a repository owner through their GitHub profile without including
exploit details in public.

Never include credentials, personal data, payment data, or private devotional records
in a report or test fixture.
