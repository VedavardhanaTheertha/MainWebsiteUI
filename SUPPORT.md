# Support

- Use the [bug-report form](https://github.com/VedavardhanaTheertha/MainWebsiteUI/issues/new?template=bug.yml)
  for reproducible site or build defects.
- Use the [feature-request form](https://github.com/VedavardhanaTheertha/MainWebsiteUI/issues/new?template=feature.yml)
  for scoped proposals.
- Start with [CONTRIBUTING.md](CONTRIBUTING.md), then use the guides for
  [content](docs/CONTRIBUTE_CONTENT.md),
  [translations](docs/CONTRIBUTE_LANGUAGE.md),
  [graphics](docs/CONTRIBUTE_GRAPHICS.md), or
  [source code](docs/CONTRIBUTE_SOURCE_CODE.md).
- Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md); do not
  open a public issue for a security report.

This community project provides no guaranteed response time, uptime, or individual
support. Do not post personal, financial, payment, or confidential devotional data.
