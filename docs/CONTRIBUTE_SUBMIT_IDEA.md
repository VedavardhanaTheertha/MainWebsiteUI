# How to Submit an Idea

This document explains how to contribute a new idea for the Matha website.

## 1. Search Existing Ideas

- Check if a similar idea is already open.
- If it exists, comment with your additional thoughts.

## 2. Create a New Idea Issue

- Open a new issue titled with your idea.
- Choose a category such as "feature suggestion" or "enhancement."

## 3. Describe the Idea Clearly

- Explain the goal of the idea.
- Describe what would change and why.

## 4. List Benefits

- Explain how the idea helps devotees, contributors, or site visitors.
- Mention potential accessibility or usability gains.

## 5. Suggest a Simple Approach

- Offer a basic way the idea could be implemented if possible.
- Keep the technical detail optional; focus on the value.

## 6. Add Supporting Examples

- Reference similar features from other websites if helpful.
- Include sketches or user flow notes when available.

## 7. Follow Up on Idea

- Engage with maintainers and commenters.
- Update the idea if the scope changes or if the team requests clarification.
