# How to Report an Issue

This document explains the process of submitting a bug report or issue for the website.

## 1. Find or Create the Issue

- Search existing issues to see if the problem is already reported.
- If not, create a new issue.

## 2. Use a Helpful Title

- Use a title that summarizes the issue clearly.
- Include the page or feature if possible.

## 3. Provide Context

- Describe the device, browser, or screen size.
- Mention the section of the site affected.

## 4. Describe the Problem

- Explain what you expected to happen.
- Describe what actually happened.
- Note any error messages or broken behavior.

## 5. Share Reproduction Steps

- List the exact steps to reproduce the issue.
- Keep them short and easy to follow.

## 6. Attach Visual Evidence

- Use screenshots or recordings when helpful.
- Point out the exact location of the issue.

## 7. Include Additional Notes

- Mention whether the issue affects all users or just a specific device.
- Share any related issue numbers if you found them.

## 8. Submit and Follow Up

- Submit the issue with the appropriate labels.
- Respond to maintainer questions and provide updates.
