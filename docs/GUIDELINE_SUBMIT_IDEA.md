# Idea Submission Guidelines

This document explains how to propose new features, improvements, or content ideas for the website.

## 1. Keep Ideas Focused

- Propose one main idea per issue.
- Avoid combining many different suggestions in a single submission.

## 2. Explain the Benefit

- Describe why the idea is useful for visitors or the community.
- Focus on how it improves experience, accessibility, or devotion.

## 3. Provide an Implementation Sketch

- Include a simple description of how the feature could work.
- Use bullet points or a short example where helpful.

## 4. Link to Related Content

- Reference any similar pages or features that already exist.
- If the idea builds on existing functionality, explain the connection.

## 5. Be Realistic and Respectful

- Offer ideas that fit the site’s mission and tone.
- Avoid suggestions that conflict with the Matha’s values.

## 6. Use Clear Language

- Write the idea in plain terms.
- Keep the submission easy to read.

## 7. Ask for Feedback

- Invite maintainers to refine the idea.
- Be open to follow-up questions and suggestions.
