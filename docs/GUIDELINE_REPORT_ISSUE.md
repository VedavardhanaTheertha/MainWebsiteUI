# Issue Reporting Guidelines

This document explains how to report bugs, usability issues, or errors in the website.

## 1. Provide a Clear Summary

- Use a concise title that describes the problem.
- Avoid vague titles such as "Something is wrong." Use "Navigation menu does not expand on mobile."

## 2. Describe the Issue in Detail

- Explain what you expected to happen.
- Describe what actually happened.
- Include the page or feature where the issue occurs.

## 3. Include Reproduction Steps

- List the steps needed to reproduce the issue.
- Keep the steps simple and sequential.
- Example:
  1. Open the home page.
  2. Click the menu icon.
  3. Notice the menu does not open.

## 4. Add Supporting Information

- Include browser and device details if relevant.
- Attach screenshots or screen recordings if they help clarify the issue.
- Mention whether the issue appears consistently.

## 5. Label the Issue Correctly

- Use the correct issue category such as bug, design, or content.
- Add tags or labels if the repository uses them.

## 6. Be Respectful and Constructive

- Report issues politely.
- Focus on improving the site rather than criticizing.

## 7. Follow Up

- Respond to questions from maintainers promptly.
- Provide any additional details if requested.
